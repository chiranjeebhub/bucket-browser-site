# bucket-browser-site

Website for **Bucket Browser: Object Storage** for macOS, served with GitHub Pages from `main`.

- Home: https://chiranjeebhub.github.io/bucket-browser-site/
- Privacy policy: https://chiranjeebhub.github.io/bucket-browser-site/privacy/
- Support: https://chiranjeebhub.github.io/bucket-browser-site/support/

Plain static HTML and CSS, no build step. Screenshots in `screenshots/` come from the app's demo mode.

When the app is live, replace the placeholder App Store URL (`id0000000000`) in `index.html` with the app's Apple ID from App Store Connect.
