# bucket-browser-site

Website for **Bucket Browser: Object Storage** for macOS, served with GitHub Pages from `main`.

- Home: https://chiranjeebhub.github.io/bucket-browser-site/
- Privacy policy: https://chiranjeebhub.github.io/bucket-browser-site/privacy/
- Support: https://chiranjeebhub.github.io/bucket-browser-site/support/

Plain static HTML and CSS, no build step. Screenshots in `screenshots/` come from the app's demo mode.

The download buttons link to https://apps.apple.com/app/id6825074732.

## Direct download

The download link points to `releases/latest/download/BucketBrowser.dmg` on the app repository's [GitHub Releases](https://github.com/chiranjeebhub/Bucket_Browser/releases). `appcast.xml` is the Sparkle update feed for that edition; the app's `scripts/release-direct.sh` adds an entry to it for each release, and each entry's update archive is attached to the matching release.
